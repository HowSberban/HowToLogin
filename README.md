# HTLogin

一个 Minecraft 登录插件，支持 Paper 与 Folia 服务器。

## 功能

- 注册 / 登录 / 登出 / 改密 / 删除账号
- 密码加密存储：BCrypt（默认）或 SHA-256，登录时自动迁移到配置算法
- 暴力破解防护：连续失败超过阈值后踢出，踢出期内无法进服
- IP 免密登录：上次登录 IP 一致且未过期时自动登录
- 登录前限制：禁止移动、转视角、聊天、执行非白名单命令、与世界交互、物品交互
- 坐标保护：玩家加入前修改出生点，支持随机坐标和固定坐标两种模式，登录后传送回退出位置
- 背包保护：未登录玩家无法查看自己的背包和末影箱内容，支持 PacketEvents 数据包拦截（防止 MiniHUD 等 Mod 窥视）
- 登录/注册超时踢出，提示消息周期性重发
- 国际化（I18n）：根据客户端语言自动匹配消息，内置中英文
- 支持 SQLite 与 MySQL 存储数据（HikariCP 连接池）

## 命令

### 玩家命令

| 命令 | 别名 | 说明 |
| --- | --- | --- |
| `/login <密码>` | `/l` | 登录 |
| `/register <密码> <确认密码>` | `/reg` | 注册 |
| `/changepassword <旧密码> <新密码>` | `/changepw`、`/cp` | 修改密码 |
| `/logout` | — | 登出 |

### 管理员命令（权限 `htlogin.admin`）

| 命令 | 说明 |
| --- | --- |
| `/htlogin reload` | 重载配置和语言文件 |
| `/htlogin accounts <玩家>` | 查询该玩家 IP 下的其它账号 |
| `/htlogin forcelogout <玩家>` | 强制登出（可离线） |
| `/htlogin forcechangepw <玩家> <新密码>` | 强制改密（无需旧密码，在线玩家会被踢出重登） |
| `/htlogin forcelogin <玩家>` | 强制登录（必须在线） |
| `/unregister <玩家>` | 删除账号 |

## 配置

详见 [`config.yml`](src/main/resources/config.yml)。主要配置项：

- **数据库**：SQLite（默认）或 MySQL，连接池大小可调
- **登录**：超时时间、失败保护、提示间隔、IP 免密登录
- **密码**：长度限制、哈希算法（`bcrypt` / `sha256`）
- **行为限制**：移动、视角、聊天、命令白名单、世界交互、物品交互
- **坐标保护**：`random` 模式在主世界随机位置等待，`fixed` 模式使用固定坐标，登录后传送回退出位置
- **背包保护**：启用后未登录玩家无法看到自己的背包和末影箱，配合 PacketEvents 从数据包层面拦截物品信息
- **国际化**：默认语言、是否根据客户端语言自动匹配

## 语言文件

插件目录下 `lang/` 文件夹存放语言文件（如 `zh_CN.properties`、`en_US.properties`）。添加 `<语言>.properties` 即可支持更多语言。
